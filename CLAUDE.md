# Tasky

## What it is
Tasky is a basic to-do list mobile app. Add tasks, check them off, and see what's left, with as little friction as possible.

## Who it's for
Busy students and young professionals who want to capture tasks quickly and get on with their day.

## Design rules
- Mobile first: target device is iPhone 18 Pro, screen size 402 x 874.
- Clean and minimal: lots of whitespace, no clutter.
- One accent color only (see `context/brand.md`).
- 8px spacing system: all margins, padding, and gaps are multiples of 8px.

## Output rules
- Every prototype is a single clickable HTML file (inline CSS and JS, no external build).
- Save all prototypes in `/prototypes`.

## Folders
- `/context`: brand and project background (start with `context/brand.md`)
- `/references`: inspiration and reference material
- `/prototypes`: finished HTML prototypes
