# Tasky

Tasky is a basic, minimal to-do list mobile app for busy students and young professionals. Add tasks, check them off, and see what's left.

## View the prototype

Open the live link (GitHub Pages), or open `prototypes/home-v1.html` directly in a browser. Each prototype is a single clickable HTML file.

## Status

**v1: home screen.** Shown in an iPhone 18 Pro frame (402 x 874).
